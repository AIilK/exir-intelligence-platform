# تابلوی تحقق تارگت هیبریدها

نمایش فرودگاهی تارگت و تحقق هیبریدها: فهرست با انیمیشن ورق‌خوردن، زوم روی هر هیبرید به ترتیب رتبه و کارت جمع در پایان هر دور.

- `server.py` — سرور جدا (فقط کتابخانه استاندارد پایتون)، پیش‌فرض روی پورت 2000
- `board.html` — صفحه تابلو
- `run.bat` — اجرا

## پیش‌نیاز

داشبورد فروش (`sales`، پورت 8000) باید روشن باشد؛ داده از `/api/commission` همان‌جا با کلید داخلی `.exir_internal_key` ریشه مخزن خوانده می‌شود.
فقط خلاصه لازم برای تابلو بیرون داده می‌شود (بدون حقوق و پورسانت). داده ۲ دقیقه در سرور و ۵ دقیقه در صفحه کش می‌شود.

## تنظیم (متغیر محیطی)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOARD_PORT` | `2000` | پورت تابلو |
| `BOARD_HOST` | `0.0.0.0` | از شبکه داخلی باز است (صفحه ورود ندارد)؛ فقط همین سیستم: `127.0.0.1` |
| `SALES_API` | `http://127.0.0.1:8000` | آدرس داشبورد فروش |
| `EXIR_INTERNAL_KEY` / `EXIR_KEY_FILE` | `../.exir_internal_key` | کلید داخلی |

## دسترسی از سیستم‌های دیگر شبکه

آدرس: `http://<IP این سیستم>:2000` (سرور هنگام اجرا آدرس‌ها را چاپ می‌کند). فایروال ویندوز باید یک بار پورت را باز کند (CMD با Run as administrator):

```
netsh advfirewall firewall add rule name="Hybrid board 2000" dir=in action=allow protocol=TCP localport=2000 profile=private,domain
```

ماه دیگر: `http://localhost:2000/?month=1405/07` · کلیدها: Space مکث، فلش‌ها قبلی/بعدی.
