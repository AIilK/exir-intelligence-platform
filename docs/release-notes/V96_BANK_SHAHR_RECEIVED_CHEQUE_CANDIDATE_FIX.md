# V96 — اصلاح واقعی Candidateهای وصول چک بانک شهر

مشکل V95 فقط درصد نبود. خروجی واقعی بانک شهر نشان داد 11 ردیف «تعیین وضعیت چک عادی عهده سایر» در بانک وجود دارد، اما سند متناظر اصلاً وارد Candidateهای Matcher نشده است.

## اصلاحات
- Query `ReceivableNoteTransaction` دیگر به ترکیب سخت `State=3 AND DocumentItemType=12` محدود نیست.
- رویدادهای تاییدشده‌ای که یکی از شواهد زیر را دارند نیز وارد Candidate می‌شوند:
  - State=3
  - DocumentItemType=12
  - شرح شامل وصول
  - شرح شامل نقد
  - شرح شامل تعیین وضعیت / تعین وضعیت
- بازه Query وصول چک تا 45 روز قبل/بعد از دوره صورتحساب گسترش یافته است.
- در Matcher، سریال دقیق چک تا 45 روز اختلاف تاریخ قابل استفاده است.
- اگر سریال کامل در بانک شهر نیامده باشد ولی هم شرح بانک و هم شرح راهکاران رویداد وصول/تعیین وضعیت چک را نشان دهند، تا 7 روز اختلاف تاریخ مجاز است.
- مخرج نرخ سندخورده همچنان برگشت/خنثی‌شده و انتقال داخلی را حذف می‌کند.

## تست
17 تست مرتبط با بانک ملت، تجارت، شهر، تغییر مدت، وصول چک و درصد پاس شده‌اند.
