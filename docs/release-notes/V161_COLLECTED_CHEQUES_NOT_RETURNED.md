# V161 — وصول‌شده هرگز برگشتی محسوب نمی‌شود

## قانون قطعی
اگر آخرین وضعیت قطعی/عملیات چک دریافتی «وصول‌شده» باشد، چک در تمام گزارش‌های مالی **برگشتی/واخواست‌شده محسوب نمی‌شود**؛ حتی اگر تاریخ سررسید آن گذشته باشد.

### نتیجه
- وصول‌شده → وصول‌شده
- برگشتی/واخواست‌شده → فقط برگشتی
- سررسید گذشته به‌تنهایی وضعیت برگشتی ایجاد نمی‌کند.

## تغییرات
- وضعیت مؤثر چک از آخرین عملیات تأییدشده راهکاران استخراج می‌شود.
- اگر شرح آخرین عملیات صراحتاً «وصول شده/وصول‌شده» باشد، State=3 کسب‌وکاری می‌شود و بر State قدیمی Master اولویت دارد.
- اگر شرح آخرین عملیات برگشتی/واخواست/استرداد باشد، State=4 کسب‌وکاری می‌شود.
- گزارش برگشتی مشتری و KPI رفتار مشتری از همین وضعیت مؤثر استفاده می‌کنند.
- endpoint وضعیت چک‌های وصول‌شده/برگشتی دیگر مستقیماً Master State را ملاک قرار نمی‌دهد.
- برچسب عمومی چک وصول‌شده نیز «وصول‌شده» نمایش داده می‌شود.
