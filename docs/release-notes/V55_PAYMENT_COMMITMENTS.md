# V55 — Payment Commitments

این نسخه دستورهای پرداخت چکی راهکاران را بدون دوباره‌شماری وارد تصمیم‌گیری نقدینگی می‌کند.

## قواعد قطعی

- State 2 با سررسید آینده و بدون اتصال Type 26 به Payment قطعی: وارد Cash Flow پایه.
- State 1 با سررسید آینده: فقط نمایش در سناریوی محتاطانه.
- State 2 سررسیدگذشته سال جاری: هشدار تعیین‌تکلیف؛ تا تأیید خزانه وارد Cash Flow نمی‌شود.
- مانده سال‌های قبل: مغایرت تاریخی و خارج از پیش‌بینی.
- State 4 اجراشده: فقط از PayableNote واقعی محاسبه می‌شود.
- State 5 لغوشده: حذف.
- چک تضمینی: حذف در تمام گروه‌ها.

## API جدید

`GET /api/v1/treasury/cash-bank/commitments?horizon_days=365&limit=500&offset=0`
