# V165 — API Same-Origin / Failed Fetch Fix

در این نسخه APIهای اصلی داشبورد از مسیر same-origin `/api/v1/...` عبور می‌کنند. Vite این مسیر را مستقیماً به FastAPI روی `127.0.0.1:8000` proxy می‌کند.

## اجرا
1. `RUN_BACKEND.bat` را اجرا کنید.
2. بررسی کنید `http://127.0.0.1:8000/health` پاسخ بدهد.
3. `RUN_FRONTEND.bat` را اجرا کنید.
4. داشبورد را از `http://127.0.0.1:3000` یا IP سیستم روی پورت 3000 باز کنید.

در این مسیر، مرورگر مستقیماً به پورت 8000 درخواست نمی‌زند.
