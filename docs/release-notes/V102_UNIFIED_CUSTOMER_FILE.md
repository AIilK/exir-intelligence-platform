# V102 — پرونده یکپارچه مشتری

- مشتریان راهکاران و کارآمد با نام نرمال‌شده در یک ردیف ادغام می‌شوند.
- جستجوی مستقیم با نام مشتری به صفحه پرونده مشتری اضافه شد.
- فیلتر شعبه کارآمد حفظ شد، اما پرونده مشتری همچنان یکپارچه است.
- پروفایل مشتری همزمان جزئیات راهکاران و کارآمد را واکشی می‌کند.
- ریز چک‌ها در یک جدول واحد نمایش داده می‌شوند: چک دریافتی/پرداختی، وضعیت، سررسید، بانک، توضیحات و منبع.
- ریز حواله‌های دریافتی و پرداختی در یک جدول جدا نمایش داده می‌شوند.
- عنوان‌ها و ردیف‌های جداگانه «پرونده راهکاران / پرونده کارآمد» حذف شدند؛ ستون منبع فقط برای ردیابی داده نگه داشته شده است.
