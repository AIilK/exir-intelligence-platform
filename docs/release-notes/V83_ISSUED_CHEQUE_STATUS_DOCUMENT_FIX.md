# V83 — تشخیص سند خوردن چک پرداختی از سند تعیین وضعیت

منطق قبلی که فقط به `PayableNote.State` متکی بود کافی نبود.

در V83 چک پرداختی در یکی از این حالت‌ها سندخورده محسوب می‌شود:

1. State در وضعیت پرداخت‌شده تنظیم‌شده باشد؛ یا
2. برای همان `PayableNote` در `RPA3.PayableNoteTransaction` یک سند تأییدشده (`DocumentState=3`) با `DocumentItemType` 24/26 وجود داشته باشد و شرح آن نشان‌دهنده «تعیین وضعیت چک / وصول چک / پرداخت چک / برداشت وجه چک» باشد.

بنابراین رکوردهایی مثل:
`تعيين وضعيت چک عادي عهده ما ... وصول چ ...`
حتی اگر State اصلی هنوز 11 باشد، سندخورده و برداشت‌شده شناخته می‌شوند و از تعهدات باز و Cash Flow آینده حذف خواهند شد.
