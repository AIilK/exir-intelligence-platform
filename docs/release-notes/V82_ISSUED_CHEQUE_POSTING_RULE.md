# V82 — منطق سند خوردن چک پرداختی

- قاعده تأییدشده مالی: در راهکاران وقتی مبلغ چک از بانک برداشت می‌شود و چک از وضعیت بلندمدت به روز می‌رود، چک «سند خورده / برداشت‌شده» محسوب می‌شود.
- در نصب فعلی این وضعیت با `PayableNote.State = 28` شناخته می‌شود.
- `State = 11` فقط «باز / سند نخورده» است.
- چک سندخورده از چک‌های پرداختی باز، تعهدات آینده و Cash Flow Prediction حذف می‌شود.
- API وضعیت چک علاوه بر کد State، برچسب فارسی `posting_status_fa` و فلگ `means_accounting_posted` را برمی‌گرداند.
- در جدول چک پرداختی، ستون وضعیت به وضعیت حسابداری چک اختصاص یافته است؛ ریسک زمانی همچنان در ستون زمان باقی‌مانده مشخص است.
