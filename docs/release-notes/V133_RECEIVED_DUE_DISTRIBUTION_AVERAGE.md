# V133 — میانگین سررسید در توزیع سررسید چک دریافتی

- فقط در نمودار «توزیع سررسید / زمان‌بندی وصول چک‌های دریافتی» یک ستون جدید اضافه شد.
- ستون جدید: «میانگین سررسید (روز)».
- مبنا: میانگین تعداد روز تا سررسید چک‌های آینده (روز >= 0) در همان View فعلی.
- بنابراین فیلتر منبع، شعبه، وضعیت نگهداری، دوره و جستجو روی عدد میانگین اثر می‌گذارند.
- در بخش چک‌های پرداختی این ستون نمایش داده نمی‌شود.
- هیچ KPI یا بخش دیگری تغییر نکرده است.
