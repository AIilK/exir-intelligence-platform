# V113 — Executive Finance Manager Agent + Management Alarms

## هدف
Finance Manager از حالت «جمع‌بندی‌کننده» به «مدیر ارشد مالی هماهنگ‌کننده Agentها» ارتقا یافته است.

### وظایف
- دریافت خروجی ساختاریافته از Agentهای تخصصی
- کنترل کیفیت و تازگی داده راهکاران + کارآمد
- تفکیک سررسید آینده از معوق
- تحلیل ۷/۳۰/۹۰ روزه
- تولید Alarm تصمیم‌محور با علت، شاهد، اثر، مسئول و مهلت
- ارائه سه اقدام امروز
- هدایت مدیر به Agent تخصصی برای جزئیات

### اصل حسابداری مدیریتی
هیچ مبلغی از متن LLM ساخته نمی‌شود. مبلغ‌ها فقط از گزارش‌های canonical و Data Hub می‌آیند.

### هشدارهای اصلی
- کسری نقدینگی پیش‌بینی‌شده
- چک پرداختی سررسیدگذشته باز
- چک دریافتی معوق با سهم معنی‌دار
- نبود مانده شروع معتبر
- ناقص بودن آینده چک پرداختی کارآمد

### Prompt
Prompt کامل در `backend/app/agents/finance_manager_prompt.py` قرار دارد.
