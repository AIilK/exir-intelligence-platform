# V114 — فیلتر محل / وضعیت چک‌های دریافتی

در صفحه چک‌های دریافتی، برای هر دو منبع راهکاران و کارآمد یک فیلتر یکسان اضافه شد:

- همه وضعیت‌ها
- نزد مأمور وصول
- نزد بانک
- نزد صندوق

با تغییر فیلتر، جمع مبلغ، تعداد، سررسیدها، نمودار و ریز جدول هم‌زمان فیلتر می‌شوند.

## نگاشت یکپارچه

- راهکاران `State=1 / registered / نزد شرکت` → نزد صندوق
- راهکاران `State=2 / in_collection` → نزد بانک / در جریان وصول
- کارآمد `واگذار شده / اسناد در جریان وصول` → نزد بانک / در جریان وصول
- کارآمد `نزد صندوق` → نزد صندوق
- عبارت صریح `مأمور وصول / مامور وصول` در وضعیت، شرح یا اطلاعات آخرین عملیات → نزد مأمور وصول

برای جلوگیری از طبقه‌بندی اشتباه، «نزد مأمور وصول» فقط با شاهد صریح متنی تعیین می‌شود.

در خروجی کارآمد، `last_operation_account` و `last_operation_level4` نیز به شکل canonical به فرانت ارسال می‌شوند تا آپلودهای بعدی بتوانند محل جاری را دقیق‌تر تشخیص دهند.
