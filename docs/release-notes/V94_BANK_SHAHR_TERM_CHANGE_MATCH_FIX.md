# V94 — اصلاح Match تغییر مدت چک برای بانک شهر

- مسیر تطبیق چک پرداختی بانک شهر دیگر به وجود سریال کامل در صورت‌حساب وابسته نیست.
- اگر شرح بانک شامل نشانه‌های چک باشد و سند راهکاران از نوع تغییر مدت/تعیین وضعیت چک باشد، Candidate وارد امتیازدهی می‌شود.
- شرایط قطعی همچنان اجباری هستند: برداشت بودن تراکنش، مبلغ دقیق، تاریخ نزدیک، و عدم استفاده دوباره از سند.
- برای مسیر بدون سریال، حداکثر ۷ روز اختلاف تاریخ پذیرفته می‌شود.
- تراکنش‌های عمومی مانند ساتنا/انتقال عادی که هیچ نشانه چک ندارند، با سند تغییر مدت Match نمی‌شوند.
