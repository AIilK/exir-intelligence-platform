# V111 — فیلتر منبع حواله

در نوار فیلتر صفحه «نقد و حواله»، «منبع حواله‌ها» اضافه شده است:

- همه منابع (پیش‌فرض)
- فقط راهکاران
- فقط کارآمد

جمع سه کارت حواله، ریزگردش، نمودار روزانه و ردیف‌های انتقال/تنخواه مطابق منبع انتخاب‌شده هستند. محاسبه پیش از صفحه‌بندی انجام می‌شود. در انتخاب فقط راهکاران، شعبه کارآمد غیرفعال می‌شود. با تغییر منبع، شعبه و شماره صفحه بازنشانی می‌شوند. گزارش ذخیره‌شده Agent و تعهدات پرداخت، گزارش‌های مستقل خود هستند.

برای ارتقا از V110 این فایل‌ها را جایگزین و بک‌اند و فرانت‌اند را دوباره اجرا کنید:

- backend/app/api/treasury.py
- backend/app/services/cash_bank_movement_service.py
- frontend/app/dashboard-client.tsx

تنظیمات و داده زنده را حفظ کنید. برای نصب از نسخه‌های قدیمی‌تر، راهنمای V109 نیز داخل بسته است.
