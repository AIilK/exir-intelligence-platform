# V98 — کل تاریخچه چک‌های دریافتی کارآمد

- فایل «چک های درییافتی 2.xlsx» به‌عنوان Snapshot کامل چک دریافتی کارآمد ثبت شد.
- Snapshot قبلی 831 رکوردی جایگزین شد و 2223 چک واقعی ثبت شدند.
- در چک و سررسید کارآمد، KPIهای مستقل سررسیدگذشته / امروز / آینده / کل سبد نمایش داده می‌شود.
- هر ردیف زمان سررسید را به‌صورت «N روز گذشته»، «امروز» یا «N روز مانده» نشان می‌دهد.
- وضعیت واقعی و محل چک از Excel نمایش داده می‌شود.
- در سوابق مشتری کارآمد، تمام چک‌های تاریخی و جاری با شماره چک، صیاد، تاریخ، وضعیت، محل چک و زمان سررسید نمایش داده می‌شود.
- خلاصه هر مشتری شامل مبلغ/تعداد معوق، امروز و آینده است.
