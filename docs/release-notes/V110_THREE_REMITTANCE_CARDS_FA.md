# V110 — سه کارت حواله

بخش کارت‌های صفحه نقد و حواله فقط سه کارت دارد:

1. حواله دریافتی: حواله ورودی عملیاتی در بازه انتخابی.
2. حواله پرداختی: کل حواله‌های پرداختی، شامل انتقال بانکی و تنخواه.
3. حواله پرداختی بدون انتقال بانکی: کل حواله منهای انتقال بانک‌به‌بانک؛ تنخواه در این عدد باقی است.

مبالغ کامل به تومان و با همان تم نمایش داده می‌شوند. منطق محاسبات V109 حفظ شده است.

برای ارتقا از V109 فقط frontend/app/dashboard-client.tsx جایگزین شود و فرانت دوباره اجرا یا Build شود. برای ارتقا از V108، راهنمای نصب V109 داخل بسته را نیز اجرا کنید.
