# V95 — اصلاح درصد سندخورده بانک شهر

- مخرج نرخ سندخورده دیگر شامل «برگشت/خنثی‌شده» و «انتقال داخلی شرکت» نیست.
- `documentable_bank_row_count` به Summary اضافه شد تا نرخ روی تراکنش‌های واقعاً قابل‌سند محاسبه شود.
- رویدادهای `ReceivableNoteTransaction` که `BankAccountRef` آن‌ها خالی است، برای وصول چک از Candidateها حذف نمی‌شوند.
- شرط‌های مبلغ، جهت، تاریخ و منطق تطبیق چک همچنان برقرار است.
